# @kit/ui-lyrics

Hypit project component for a UI-lyric edit: every lyric line is acted out by a fake interface, every
sung word arrives as its own `Instant`.

```svml
<ui:Edit id="edit" timeline={t.timeline} within={canvas.bounds} during={t.window}
  variant="chorus" label="ARTIST // EDIT" timecode="13.95"
  font-ui={f-ui} font-bold={f-bold} font-black={f-black} font-mono={f-mono}>
  <ui:Word id="w00" text="Я" at={t.w00}/>
  ...
</ui:Edit>
```

- `variant` names a scene set: the file `client/scenes/<variant>.js`, which registers
  `SCENE_SETS.<variant>`. Scenes address words by index, so the number and order of `Word` children
  are bound to that file. Their Instants may move freely: the animation follows the word.
- `during` is the edit's lifetime; `timecode` is the track time at the first frame (HUD REC counter).
- Fonts: four `media:FontStack` (Inter 600 / 800 / 900, JetBrains Mono 700).
- Output: `edit.visual`. The canvas is fixed at 1080×1080.

Build: `npm run build -w @kit/ui-lyrics` from the project root (runs `build.mjs`, then `tsc`).
`productions/<edit>/main.svml` is generated by `tools/gen_source.mjs`; do not edit it by hand.

Scene API, grammar and workflow: `skills/creative/ui-lyric-edit.md` in the OpenMontage repo.
